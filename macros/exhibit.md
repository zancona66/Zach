# /exhA … /exhL — Exhibit Cover Sheet

Use: One cover sheet per exhibit (A through L). Insert before the
exhibit document itself in the packet.

---

```
═══════════════════════════════════════════════════════════════
                          EXHIBIT [LETTER]
═══════════════════════════════════════════════════════════════

Matter:        ZRA v. [DEFENDANT]
Index No.:     [INDEX]
Court:         Supreme Court of the State of New York,
               County of New York

Description:   [SHORT DESCRIPTION — e.g., "Email thread between
               ZRA and [PARTY], April 11, 2026 – April 18, 2026"]

Date(s) of
the document:  [ABSOLUTE DATE OR DATE RANGE]

Source /
Custodian:     [WHERE IT CAME FROM — e.g., "ZRA personal Gmail
               archive; exported April 30, 2026"]

Authentication
basis:         [How this exhibit will be authenticated — e.g.,
               "Notice to Admit ¶ 7", "Witness testimony of
               [NAME]", "Self-authenticating under CPLR 4540"]

Cited in:      Verified Complaint ¶¶ [#, #, #]
               Affirmation of [NAME] ¶¶ [#, #]

Page count:    [#] pages (Bates [PREFIX] [START] – [END])

═══════════════════════════════════════════════════════════════
                Prepared by pro se plaintiff.
═══════════════════════════════════════════════════════════════
```

## Suggested Exhibit A–L map  (edit per matter)
| Letter | Description |
|---|---|
| A | Lease and any addenda |
| B | Security deposit receipt / payment proof |
| C | Move-in / move-out condition photos |
| D | Demand letter and proof of delivery |
| E | Email correspondence chronological |
| F | Text / SMS chronological |
| G | Inventory of personal property |
| H | Bank / accounting records |
| I | Insurance policy and tender correspondence |
| J | Witness statements / affidavits |
| K | Third-party communications |
| L | Catch-all / supplemental |

## Self-check
- One cover sheet per exhibit? [Y/N]
- Description matches in-text citation in pleadings? [Y/N]
- Bates range continuous, no gaps? [Y/N]
- Authentication basis identified? [Y/N]
