# /torah — Torah Engine

Use: When the active task touches justice, honesty, property,
contracts, harm, speech, or personal conduct — or on explicit user
invocation.

Output: short ethical link inserted near end of Full Draft.
Length: ≤ 8 lines. Format: SOURCE → INTERPRETATION → APPLICATION
→ LIMITS.

---

## Sourcing rules (non-negotiable)
Cite a real reference for every non-trivial claim. No paraphrase
without a cite. No invented attributions.

Citation formats:
- Tanach:    Book chapter:verse        e.g., Devarim 16:20
- Mishnah:   tractate perek:mishnah    e.g., Avot 1:18
- Gemara:    tractate daf+amud         e.g., Bava Metzia 58b
- Halacha:   Shulchan Aruch + siman/se'if + commentary if used
             e.g., SA Choshen Mishpat 25:1
- Midrash:   collection + parsha/pasuk e.g., Bereishit Rabbah 8:5
- Rishon:    name + work + ref         e.g., Rambam, Hilchot De'ot 6:7
- Acharon:   name + work + ref         e.g., Chofetz Chaim 1:1

Quote discipline: short direct quotes only; prefer paraphrase + cite.

---

## Required separation in output
- **SOURCE**          (what the text says)
- **INTERPRETATION**  (how sages/poskim understand it)
- **APPLICATION**     (how it maps to ZRA's situation)
- **LIMITS**          (where a posek must be consulted)

---

## Template (paste into Full Draft)

```
Ethical Link (Torah)
SOURCE:         [Hebrew if short, then English] — [Citation]
INTERPRETATION: [One sentence on how the tradition reads it.]
APPLICATION:    [One sentence mapping to the case at hand.]
LIMITS:         [One line on where a competent posek should rule.]
```

## Example (litigation honesty)
```
Ethical Link (Torah)
SOURCE:         "מדבר שקר תרחק" — Shemot 23:7
                ("Distance yourself from a false matter.")
INTERPRETATION: Sefer HaChinuch §74 — duty of strict truthfulness
                in adjudication, broader than mere perjury.
APPLICATION:    Every fact in our Verified Complaint must be
                personally verifiable; remove any allegation we
                cannot support with an exhibit or sworn witness.
LIMITS:         For tactical questions of pleading vs. proof,
                consult a competent posek and litigation counsel.
```
