# zra-special-ops scaffold

Reusable skeleton for high-rigor tasks.

## Files
- `task-brief.md`: intake template to capture scope, facts, assumptions, and deliverables.
- `validation-log.md`: execution/verification template for commands, outputs, and gaps.

## Usage
1. Copy both files into your working folder.
2. Fill `task-brief.md` before implementation.
3. Fill `validation-log.md` as checks run.
4. Include assumptions, risks, and unresolved blockers before handoff.
