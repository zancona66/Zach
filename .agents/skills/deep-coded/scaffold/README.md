# deep-coded scaffold

Reusable skeleton for depth-first coding tasks.

## Files
- `task-brief.md`: intake template to capture scope, invariants, assumptions, and validation plan.
- `validation-log.md`: execution/verification template for commands, outputs, and gaps.

## Usage
1. Copy both files into your working folder (typically `.agents/runs/YYYY-MM-DD-<task-name>/`).
2. Fill `task-brief.md` before touching code.
3. Fill `validation-log.md` as inspection, edits, and checks proceed.
4. Before handoff, confirm: assumptions surfaced, validation run, risks recorded, confidence stated.
